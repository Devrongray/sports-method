## Rule power check

If Pinnacle were perfectly calibrated (slope exactly 1 every season), the pre-registered all-seasons-in-band rule would still fail with probability **90%**, given the standard errors observed. Seasons whose slope differs from 1 by more than 2 SE: 2023/24.
